# Template: RBAC Role Hierarchy

Standard role structure for enterprise Snowflake with AI/ML-ready access patterns.

## Role Hierarchy

```
ACCOUNTADMIN
  └── SYSADMIN
        ├── DATA_ENGINEER
        │     └── DATA_ANALYST
        │           └── BI_VIEWER
        ├── DATA_SCIENTIST
        ├── ML_ENGINEER
        └── APP_SERVICE
```

## SQL

### Create Functional Roles

```sql
CREATE ROLE IF NOT EXISTS DATA_ENGINEER;
CREATE ROLE IF NOT EXISTS DATA_ANALYST;
CREATE ROLE IF NOT EXISTS DATA_SCIENTIST;
CREATE ROLE IF NOT EXISTS ML_ENGINEER;
CREATE ROLE IF NOT EXISTS APP_SERVICE;
CREATE ROLE IF NOT EXISTS BI_VIEWER;
```

### Establish Hierarchy

```sql
GRANT ROLE BI_VIEWER TO ROLE DATA_ANALYST;
GRANT ROLE DATA_ANALYST TO ROLE DATA_ENGINEER;
GRANT ROLE DATA_ENGINEER TO ROLE SYSADMIN;
GRANT ROLE DATA_SCIENTIST TO ROLE SYSADMIN;
GRANT ROLE ML_ENGINEER TO ROLE SYSADMIN;
GRANT ROLE APP_SERVICE TO ROLE SYSADMIN;
```

### Database-Scoped Access

```sql
GRANT USAGE ON DATABASE {{database}} TO ROLE DATA_ANALYST;
GRANT USAGE ON ALL SCHEMAS IN DATABASE {{database}} TO ROLE DATA_ANALYST;
GRANT SELECT ON ALL TABLES IN DATABASE {{database}} TO ROLE DATA_ANALYST;
GRANT SELECT ON FUTURE TABLES IN DATABASE {{database}} TO ROLE DATA_ANALYST;

GRANT ALL PRIVILEGES ON SCHEMA {{database}}.{{schema}} TO ROLE DATA_ENGINEER;
GRANT ALL PRIVILEGES ON FUTURE TABLES IN SCHEMA {{database}}.{{schema}} TO ROLE DATA_ENGINEER;
```

### ML-Specific Grants

```sql
GRANT CREATE TABLE, CREATE VIEW, CREATE MODEL ON SCHEMA {{database}}.{{ml_schema}} TO ROLE DATA_SCIENTIST;
GRANT CREATE TABLE, CREATE VIEW, CREATE MODEL, CREATE SERVICE ON SCHEMA {{database}}.{{ml_schema}} TO ROLE ML_ENGINEER;
```

### Warehouse Grants

```sql
GRANT USAGE ON WAREHOUSE WH_ANALYTICS TO ROLE DATA_ANALYST;
GRANT USAGE ON WAREHOUSE WH_ANALYTICS TO ROLE BI_VIEWER;
GRANT USAGE ON WAREHOUSE WH_ETL TO ROLE DATA_ENGINEER;
GRANT USAGE ON WAREHOUSE WH_ML TO ROLE DATA_SCIENTIST;
GRANT USAGE ON WAREHOUSE WH_ML TO ROLE ML_ENGINEER;
```

## Customization

Replace `{{database}}`, `{{schema}}`, and `{{ml_schema}}` with your actual object names. Adjust `ALLOWED_VALUES` for roles based on organizational structure.
