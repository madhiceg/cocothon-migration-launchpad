# Organizational Readiness

**Weight:** 5% of overall AI Readiness Score
**Max Score:** 100

Technology alone does not make an enterprise AI-ready. This dimension assesses the human and process factors: skills, culture, strategy, and cross-functional alignment. Unlike other dimensions, this one relies primarily on survey and interview data rather than automated Snowflake probes.

---

## Criteria

### 1. AI Literacy & Skills (Weight: 25%)

Team has skills to build, deploy, and maintain AI/ML solutions.

| Score | Condition |
|-------|-----------|
| 0-20 | No AI/ML skills on data team |
| 21-40 | 1-2 team members with ML knowledge |
| 41-60 | Dedicated data science team, limited Snowflake ML experience |
| 61-80 | DS team proficient in Snowpark ML, Cortex functions |
| 81-100 | Cross-functional AI competency with MLOps engineers and AI champions |

**Assessment Method:** Survey / interview

---

### 2. MLOps & DataOps Culture (Weight: 25%)

CI/CD, version control, and operationalization practices for data + ML.

| Score | Condition |
|-------|-----------|
| 0-20 | No version control for data assets |
| 21-40 | Git for application code only |
| 41-60 | Git integration for SQL/dbt, basic CI/CD |
| 61-80 | Full DataOps: Git + CI/CD + testing + deployment automation |
| 81-100 | MLOps: model CI/CD + monitoring + retraining triggers + feature store CI |

**Snowflake Signals:**
- Git integration repositories
- Snowflake CLI / Snowpark usage

---

### 3. Cross-Functional Alignment (Weight: 25%)

Business, data engineering, and AI teams aligned on AI strategy.

| Score | Condition |
|-------|-----------|
| 0-20 | AI is IT-only initiative |
| 21-40 | Executive sponsorship but siloed teams |
| 41-60 | Data council or governance board established |
| 61-80 | Business-embedded analytics with AI use-case roadmap |
| 81-100 | AI Center of Excellence with federated execution model |

**Assessment Method:** Survey / interview

---

### 4. Documented AI Strategy (Weight: 25%)

Formal AI strategy aligned with data strategy and business goals.

| Score | Condition |
|-------|-----------|
| 0-20 | No AI or data strategy document |
| 21-40 | Data strategy exists, AI mentioned as aspiration |
| 41-60 | AI strategy drafted with prioritized use cases |
| 61-80 | AI strategy with KPIs, budget, and governance framework |
| 81-100 | Living AI strategy with quarterly reviews, ROI tracking, and feedback loops |

**Assessment Method:** Survey / interview
