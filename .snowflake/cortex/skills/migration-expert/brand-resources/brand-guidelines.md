# kipi.ai Brand Guidelines — CoCoDuo Document Generation

*Extracted from the official kipi.ai Visual Brand Guide*

## Brand Identity

kipi.ai is a data and AI consulting company. Tagline: **"Data-Driven Business Reimagined."** The brand is modern, clean, minimal, and technology-forward. All documents and reports generated by CoCoDuo must adhere to these guidelines.

### Typography Rules
1. **Never use kipi Green `#B3D943` for body text** — insufficient contrast on white
2. kipi Green is for **accents only**: underlines, borders, icons, tags, brand labels, buttons
3. Section headers use **kipi Black** with a **kipi Green accent underline** (2px solid, 60px width)
4. **Headings for marketing/impact** may use uppercase (e.g., "TRANSFORMING DATA INFRASTRUCTURE WITH SNOWFLAKE.")
5. Document body text is left-aligned, never center-aligned
6. Line height: 1.6 for body, 1.3 for headings

## Company Name Usage — CRITICAL

- The correct form is: **kipi.ai** — always all lowercase, always include ".ai"
- Never write as: "Kipi.ai", "KIPI.AI", "Kipi AI", "KipiAI", "Kipi", "KIPI"
- In sentences: "kipi.ai is a data and AI consulting company"
- When starting a sentence, still use lowercase: "kipi.ai transforms..."
- Team members are referred to as **kipians** (lowercase)
- The company name includes the ".ai" — never shorten to just "kipi"
- **NEVER apply CSS `text-transform: uppercase` to any element containing "kipi.ai"** — this violates brand guidelines by rendering it as "KIPI.AI"
- **NEVER use `text-transform: uppercase` on brand labels, headers, or any text that might contain the company name**
- Acceptable uppercase usage: standalone labels like "PHASE 1", "CRITICAL", table column headers (only when they do NOT contain "kipi.ai")

## Logo Usage

### Logo Variants
1. **Full logo (green on white/light)** — Globe icon + "kipi.ai" in green. Primary usage on light backgrounds.
2. **Full logo (black on white)** — Globe icon + "kipi.ai" in black. For monochrome contexts, print.
3. **Full logo (green on dark)** — Globe icon + "kipi.ai" in green on dark backgrounds. For dark sections, cover pages.
4. **Full logo (white on dark)** — Globe icon + "kipi.ai" in white on dark backgrounds.
5. **Icon only (green)** — Globe icon only in kipi Green. For favicons, watermarks, small formats.
6. **Icon only (black)** — Globe icon only in black. For monochrome small formats.

### Logo Rules
- Maintain clear space around logo (minimum: height of the "k" in kipi)
- Never stretch, rotate, skew, or alter logo proportions
- Never place green logo on green or similarly colored backgrounds
- Never place the logo on busy/photographic backgrounds without a container
- Never add effects (shadows, outlines, gradients) to the logo
- Minimum size: 80px width for full logo, 24px for icon-only

## Voice & Tone — "Write like Kipi"

### Core Voice Attributes
- **Innovative**: Lead with forward-thinking ideas, reference cutting-edge technology
- **Approachable**: Avoid jargon overload, explain complex concepts clearly
- **Precise**: Be specific with numbers, tools, and recommendations — no vague advice
- **Customer-Centric**: Always frame recommendations in terms of customer outcomes and value

### Tone of Voice Hierarchy
1. **Data-Driven** — Lead with evidence, metrics, and concrete data points
2. **Approachable** — Professional but not stiff, technical but not intimidating
3. **Precise** — Specific tool names, exact numbers, clear timelines
4. **Customer-Centric** — Frame everything around what the customer gains

### Writing Principles for Documents
- Start with the customer's problem, then present the solution
- Use active voice ("We recommend..." not "It is recommended...")
- Include specific numbers from the assessment data
- Quote the SA's Architecture Nuances when relevant
- End sections with clear, actionable next steps

- Use the dark navy (`#2C3E6B`) for hero/cover sections
- kipi Green (`#B3D943`) for accent elements and CTAs
- Keep slides/sections minimal — one key message per section
- Use generous whitespace

## Do's and Don'ts

### Do
- Use kipi Green `#B3D943` as the primary accent (borders, underlines, brand labels, dividers, buttons)
- Use Proxima Nova as the typeface for all documents (Helvetica Neue as fallback)
- Keep layouts clean with generous whitespace
- Use kipi Black `#1A1A1A` for all headings and primary text
- Use Dark Navy `#2C3E6B` for cover pages and hero sections
- Maintain high contrast ratios (WCAG AA minimum)
- Use Light Green `#E8F5C8` for callout/info box backgrounds
- Always write the company name as "kipi.ai" (lowercase k, include .ai)

### Don't
- Write "Kipi.ai", "KIPI.AI", "Kipi AI", or any capitalized variant — always "kipi.ai"
- Apply CSS `text-transform: uppercase` to any element containing "kipi.ai"
- Use kipi Green for body text or large text blocks (insufficient contrast)
- Use `#ADDB1A` — this is NOT the correct kipi Green (use `#B3D943`)
- Use colored backgrounds behind body text (except light gray for table rows)
- Use gradients, shadows, or heavy decorative elements
- Use Inter or Poppins font — the correct font is Proxima Nova
- Use navy `#0f1e41` — the correct dark is `#2C3E6B` (Dark Navy) or `#1A1A1A` (kipi Black)
